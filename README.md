# EcoSustain - MSME Green Sustainability Platform 🌿

EcoSustain is an all-in-one web-based sustainability management and carbon accounting platform designed specifically for Micro, Small, and Medium Enterprises (MSMEs / UMKM).

## 🚀 Key Features

- **Sustainability Dashboard**: Real-time KPI tracking for energy, water, waste circularity, and total carbon footprint ($kg\ CO_2e$).
- **Green Data Input**: Monthly resource input with automated emission calculations using standard conversion coefficients.
- **Innovation Tracker**: Log and monitor green initiatives, ROI, and estimated annual carbon savings.
- **Smart Recommendations**: Sector-tailored efficiency insights with one-click conversion to actionable conservation targets.
- **Eco Targets**: Measurable goal setting and progress monitoring.
- **Sector Benchmarking**: Compare your eco performance with industry peers (F&B, Fashion, Crafts, Retail, Manufacturing) via 5-dimension radar charts.
- **Eco Academy**: Practical sustainability guides and interactive quizzes with certification badges.
- **Reports & Audit**: Print-ready ESG and Corporate Green Audit documentation for loan applications and green certifications.

## 🛠️ Tech Stack

- **Frontend**: HTML5, Modern CSS (Glassmorphism, responsive, dark/light theme), Vanilla JavaScript
- **Libraries**: [Chart.js](https://www.chartjs.org/), [Lucide Icons](https://lucide.dev/)
- **Data Storage**: Client-side `localStorage` (no external database server required)

## 💻 Getting Started Locally

1. Clone this repository:
   ```bash
   git clone git@github.com:azulaeldeathdante/green-sustainability-app.git
   cd green-sustainability-app
   ```

2. Run the application:
   - **Option A (Python server)**:
     ```bash
     python serve.py
     ```
     Then open [http://localhost:5500](http://localhost:5500) in your browser.
   - **Option B (Direct)**:
     Double-click `index.html` to open directly in any modern web browser.
